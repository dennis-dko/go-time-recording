        Maintenance mode
        
        
        Turns everyone else away with a notice while the installation stays running. Use it before restoring or moving the database: time recorded during that window is lost when the snapshot goes back, and whoever recorded it has no way to know.
        
        
        While it is on, only this built-in administrator can work. Everyone else, including other administrators, is turned away — that is the point.

        Logging, metrics and tracing
        
        
        
        
        Saved here and applied the next time the application starts. None of it can be switched over while the application runs: the log level is read, the metrics port is bound and the trace exporter is built while it starts. A field left following the configuration file keeps its value from there.
        
        
        The metrics port asks for no sign-in, is not covered by TLS, and serves Go's profiling endpoints beside the metrics — anywhere it is reachable, so is a heap dump. Expose it to your monitoring only.
        
        
        
          
          
          
          
          
        
        
        
        
        Running deploy/compose.tracing.yaml beside the application? Then it is exporter OTLP and collector jaeger:4317, and the traces are read at http://127.0.0.1:16686.

Unknown users are created locally on their first successful sign-in.
        
        
        
          
          
          
          
        
        
        
        
          
          
          
          
          
          
          
          
          
          
        
        
        
        
          
          
        
        
        
        
      
        

      
        
        
        Directory synchronisation
        
        
        Reconciles the users with the directory. LDAP is only ever read, never changed.
        
        
        Careful: accounts missing from the directory are deleted here, together with their recorded time, own projects and tokens. This cannot be undone. Always run the preview first.
